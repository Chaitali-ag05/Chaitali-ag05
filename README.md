### 🎬 Movie Review Sentiment Classifier

**Python • Scikit-learn • NLTK • Streamlit**

An NLP-based sentiment classifier trained on 50,000 IMDB movie reviews.

**Highlights**

- Text preprocessing and TF-IDF vectorization
- Evaluated Logistic Regression, SVM, and Naive Bayes
- Achieved **88% accuracy** using Logistic Regression
- Deployed as an interactive Streamlit application

🔗 Repository: https://github.com/Chaitali-ag05/Movie-Review-Sentiment-Classifier
