## ⭐ Featured Projects

### 🏭 Enterprise Asset & Operations Management Platform
**Java • Spring Boot • Spring Security • JWT • PostgreSQL • Flyway • React • TypeScript • Vite • Recharts**

A full-stack, role-based platform (Admin / Manager / Technician / Employee) for managing enterprise assets and operations end-to-end.

**Highlights**
- 4 distinct user roles with JWT-based authentication and role-based access control
- Layered Spring Boot backend with PostgreSQL, JPA-Hibernate, and Flyway migrations
- Issue → Work Order → Maintenance Record workflow with OTP-verified registration
- React/TypeScript frontend with Recharts dashboards and secure CSV exports

🔗 Repository: https://github.com/Chaitali-ag05/Enterprise-Asset-Management

### 🎬 Movie Review Sentiment Classifier
**Python • Scikit-learn • NLTK • Streamlit**

An NLP-based sentiment classifier trained on 50,000 IMDB movie reviews.

**Highlights**
- Text preprocessing via cleaning, tokenization, and TF-IDF vectorization
- Evaluated Logistic Regression, SVM, and Naive Bayes models
- Achieved **88% accuracy** using Logistic Regression
- Deployed as an interactive Streamlit app with real-time predictions

🔗 Repository: https://github.com/Chaitali-ag05/Movie-Review-Sentiment-Classifier
