- Deposit and withdraw money

- Search accounts by customer name
- Input validation and custom exception handling

**Concepts**
- Object-Oriented Programming
- Layered Architecture
- Repository Pattern
- Collections Framework
- Java Streams API
- Lambda Expressions
- UUID
